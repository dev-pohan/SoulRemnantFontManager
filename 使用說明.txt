Soul's Remnant 字型管理器－簡易操作說明
=========================================

【使用前注意】
本工具並非遊戲官方程式，會修改 Soul's Remnant 的 Godot PCK 封包。
使用前請自行評估遊戲規範及帳號風險。建議先關閉遊戲與 Steam。


一、第一次安裝
--------------

1. 將下載的 ZIP 完整解壓縮，不要直接在壓縮檔內執行。

2. 執行對應平台的程式：
   Windows：SoulRemnantFontManager.exe
   Linux／macOS：soul-remnant-font-manager

3. 在主選單選擇：
   [2] 設定「點陣」模式字型
   [3] 設定「傳統」模式字型

4. 輸入 .ttf 或 .otf 字型檔的完整路徑。
   將字型檔拖曳到視窗內，通常可以直接填入完整路徑。
   直接留空則使用遊戲內建字型。

5. 如需調整字體大小，選擇 [4]。
   1.00× 是遊戲原始大小；可分別調整六類文字，或一次全部調整。

6. 回到主選單選擇 [1]「快速安裝／修復」。
   如果 Steam 正在執行，請依提示正常關閉；工具完成後會重新開啟 Steam。

7. 從 Steam 正常啟動遊戲。
   遊戲內的「字體＝點陣／傳統」選項會套用各自設定的字型。


二、之後更換字型或大小
----------------------

再次執行管理器，使用 [2]、[3] 或 [4] 修改即可。
已完成快速安裝時，管理器會同步更新遊戲補丁。


三、更新管理器
--------------

下載並解壓縮新版，執行新版程式一次。
管理器會自動更新 Steam 啟動遊戲時使用的已安裝副本。


四、狀態檢查與解除安裝
----------------------

[6] 狀態檢查：顯示遊戲路徑、目前字型、字體倍率與 PCK 狀態。

[7] 解除安裝：依畫面提示輸入 YES，還原 PCK 與本工具管理的
Steam 啟動選項。解除安裝前也請先關閉遊戲與 Steam。


五、常見問題
------------

1. 找不到遊戲：
   依提示輸入包含「Soul's Remnant.pck」的遊戲資料夾。

2. 字型沒有變化：
   先用 [6] 確認狀態，再執行 [1]「快速安裝／修復」，並重新啟動遊戲。

3. Steam 更新遊戲後失效：
   正常從 Steam 啟動一次；啟動前置程式會自動檢查並重新套用。
   若仍無效，重新執行管理器的 [1]「快速安裝／修復」。

4. Windows 阻止執行：
   本工具目前未簽署。請只從本專案的 GitHub Releases 下載，確認來源後
   再決定是否於 Windows SmartScreen 選擇「其他資訊」→「仍要執行」。

5. macOS 阻止執行：
   本工具目前未簽署，可至「系統設定」→「隱私權與安全性」允許開啟。
